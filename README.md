# 🛋️ HoloRoom

HoloRoom is a collaborative furniture and décor shopping platform that combines e-commerce with Augmented Reality (AR), allowing users to visualize furniture in their own space before making a purchase. The platform also features an AI-powered assistant capable of both text and voice conversations, providing an immersive shopping experience directly within AR mode.

## ✨ Features

* 🛒 Furniture and décor e-commerce platform
* 📱 Augmented Reality room visualization
* 🪑 Place and preview furniture in your own environment
* 🤖 AI chatbot for shopping assistance
* 🎤 Voice conversations with the AI assistant in AR mode
* 👥 User authentication and personalized dashboards
* 📦 Product browsing and management

## 🚀 Running the Project

Clone the repository:

```bash
git clone https://github.com/abdouiscoding/HoloRoom.git
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

> Additional backend and environment configuration may be required depending on your local setup.
